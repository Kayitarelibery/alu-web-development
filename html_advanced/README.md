# HTML Advanced

## Description

This project is the first step in rebuilding a full landing page from a Figma design file, using pure semantic HTML — no CSS or styling yet. The goal is to translate a designer's wireframes into a well-structured HTML skeleton: correct use of `header`, `main`, `section`, `footer`, and semantic tags like `h1`–`h3`, `blockquote`, `button`, and `img`, laid out in the exact order and nesting the design calls for.

The page being rebuilt is a school/course landing page containing:

- A **header** with a clickable logo and navigation links
- A **banner** introducing the platform, with a call-to-action button and a 4-item feature grid
- A **quote** section featuring a student testimonial
- A **videos** section showcasing student stories with ratings
- A **membership** section listing available plans
- An **FAQ** section with common questions laid out in two rows
- A **footer** with the logo, social links, and copyright text

Styling (CSS) is intentionally left out at this stage — the focus here is purely on getting the HTML structure and semantics right before any visual design is applied in later projects.
