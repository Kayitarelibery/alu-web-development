# CSS Advanced

## Description

This project builds directly on [HTML Advanced](../html_advanced) — the same `index.html` skeleton is styled here with pure CSS to match the "Smile School" landing page design from Figma. No new HTML tags are introduced; this project is about applying `styles.css` to bring the existing semantic structure to life: layout, color, typography, spacing, and imagery.

Sections styled in this project:

- **Header** — contained/centered logo and navigation
- **Banner** — hero heading ("Get schooled"), background image, and feature grid
- **Quote** — student testimonial with rounded author photo
- **Videos** — "Popular" video list with ratings and author info
- **Membership** — "Free" plan comparison grid
- **FAQ** — two-row grid of question/answer pairs
- **Footer** — logo, social links, and copyright
